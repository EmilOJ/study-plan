# Core kit checklist

Use any suitable distributor. The file keeps its original name for convenience; it no longer assumes Amazon stock, prices or exact substitutes. The full specification and phase-2 requirements are in [Parts List.md](Parts%20List.md).

- [x] NUCLEO-U575ZI-Q and NUCLEO-C031C6, as stated in the original plan.
- [x] Breadboard, jumper wires and basic passives, as stated in the original plan; verify inventory.
- [ ] Adafruit 4517 LSM6DSOX + LIS3MDL, with required headers/cable.
- [ ] SparkFun SAM-M10Q breakout with UART/PPS access and a 3.3 V USB-UART adapter.
- [ ] Multimeter and PulseView-compatible logic analyzer with documented input limits.
- [ ] Soldering iron, appropriate power supply, solder, flux, wick and header hardware.
- [ ] Current-limited bench supply and documented regulator module, selected before PCB design.
- [ ] USB data cables, test leads, resistors/decoupling, fuses/holders and project-specific protection parts.
- [ ] Existing suitable USB camera, flat printed calibration target and rigid mounting board.
- [ ] Complete-assembly enclosure/fit supplies, commercial fallback box and optional coupon/custom print.
- [ ] Borrowed/shared oscilloscope access for analog waveform measurements, if available.

Do not buy a generic MOSFET or transceiver solely from a similar part name. Check its exact guaranteed drive/supply/interface limits. Get PCB/assembly/print quotes after design review; the December 15 and January print dates are targets subject to release gates.
